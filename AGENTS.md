# Agent Instructions

This file supplements existing repository security, privacy and authorization instructions. It does not override stronger local rules.

## Mandatory portfolio visual rule — One Cohesive Cinematic Composition (founder directive 2026-11-04)

All authorized design, implementation, QA and delegated agents: treat **every app, page, website and screen as one cohesive cinematic composition**, not disconnected UI blocks. Establish one focal hierarchy and a consistent atmosphere through navigation, typography, imagery, depth, light, spacing, interaction and transitions; include real loading, auth, form, error, empty, mobile and account states where applicable.

**Keep each product's distinct canonical brand, audience, claims, characters, and functionality.** Do not copy an unrelated product's palette or replace legitimate application behavior with visual decoration. Start by observing real routes, source, current design tokens and rendered screens. Preserve accessibility (semantic meaning, keyboard/focus, contrast, reduced motion), responsiveness, performance, truthful content, private data boundaries and working business flows.

For each changed route, verify real screenshots and interactions across representative desktop/mobile sizes and relevant state transitions on the exact candidate head, and record proof separately from source changes. A written design policy is not a completed visual overhaul or evidence of deployment. Existing founder approvals, security/privacy/merge/release controls remain fully in force. Do not publish, merge, deploy, or disclose private source merely because this rule exists.
