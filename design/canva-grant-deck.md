# SolContinuity grant deck outline

1. **Problem:** decentralized programs still depend on centralized application infrastructure.
2. **Failure story:** one RPC, frontend, API, or indexer can stop access.
3. **Product:** SDK, CLI, analytics, recovery manifest, and evidence console.
4. **Why Solana:** direct support for censorship resistance, decentralization, and developer tooling.
5. **Technical architecture:** TypeScript core, Node API, Python analytics, self-hostable console.
6. **Proof:** strict builds, tests, Playwright artifacts, provider-operator quorum.
7. **Milestones:** five bounded deliverables tied to $10,000.
8. **Pilot:** ProofRail demonstrates DAO coordination and Solana payments.
9. **Open-source value:** another developer can deploy without the founding team.
10. **Truth boundary:** application-layer resilience, not consensus redesign.
