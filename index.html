Don’t trust one route.

SolContinuity keeps an application from silently trusting a single route, operator, hosted interface, API, or recovery path. It reads from several independent providers, keeps their disagreements as evidence, and fails over when one goes bad.

Solana is the first implemented adapter and its live proof environment. The core is platform-neutral.

How a read survives one bad route

A request goes to several independently operated routes. Their answers are compared, not trusted by default.

  1. Routes

    • provider-a independent operator
    • provider-b independent operator
    • provider-c independent operator

    IDs match the provider entries in examples/continuity-manifest.json. This page shows no health or latency because it has no live feed.

  2. Quorum

    Agreement is checked against minimumRouteAgreement in the manifest.

  3. Outcomes

    • Agreed. Value returned with per-route evidence.
    • Disagreed. Disagreement kept as evidence, not averaged away.
    • Route failed. Failover to the next route, failure recorded.
    • Exported. Portable evidence record.

What runs today

  • Platform-neutral continuity manifest, with legacy Solana compatibility
  • Strict multi-route JSON-RPC client with provider-aware quorum and failover
  • Per-route latency, value, operator, and error evidence
  • Deterministic continuity audit across routes, targets, recovery, and evidence
  • Solana adapter: blockhash health, pre-signed broadcast, independent confirmation on Devnet
  • Self-hosted Console with optional session authentication

No live data on this page

This site is static. It shows no provider health, transaction results, or quorum outcomes. The Console reads evidence from a server you run yourself.

Not claimed yet

Stated plainly so nobody has to infer it.

  • Universal HTTP continuity
  • Automatic EVM transaction semantics
  • Validator or consensus guarantees
  • Support for every chain
  • Proof that providers are honest, or that censorship is impossible

New adapters must keep the same evidence and recovery contracts before they count as supported.

Run it

npm ci --ignore-scripts --no-audit --no-fund
npm run verify
npm start

Then open the Console on 127.0.0.1:4173. Signed transactions are accepted only as pre-signed input; the tooling never loads private keys.

Open source. Registry publishing, deployment, spending, live transaction tests, and merges are founder decisions.
